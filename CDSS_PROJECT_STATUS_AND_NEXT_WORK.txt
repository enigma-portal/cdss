5. ARCHITECT RECOMMENDATIONS FOR AN EXCEPTIONAL PROTOTYPE
============================================================

Analyst workflow
----------------
[RECOMMEND] Incident states: New, Acknowledged, Investigating, Contained, Closed.
[RECOMMEND] Assign incident to an analyst with ownership and timestamps.
[RECOMMEND] Disposition: True Positive, Benign Positive, False Positive, Duplicate.
[RECOMMEND] Analyst notes and evidence timeline.
[RECOMMEND] Bulk acknowledge/close only with confirmation and audit records.
[RECOMMEND] Track Mean Time to Acknowledge and Mean Time to Resolve.

Risk and asset intelligence
---------------------------
[RECOMMEND] Asset criticality (Critical/High/Normal/Low) set by admins.
[RECOMMEND] Increase priority when a risky event affects a critical asset.
[RECOMMEND] Separate event severity, confidence and business impact.
[RECOMMEND] Explain every priority change and keep the old score for audit.
[RECOMMEND] Trend graphs for risk, incidents and vulnerabilities over time.

Connector architecture
----------------------
[RECOMMEND] Use adapters: Wazuh today; Splunk, Elastic and Microsoft Sentinel later.
[RECOMMEND] Normalize all source events into one vendor-neutral event schema.
[RECOMMEND] Each connector declares health, capabilities and supported fields.
[RECOMMEND] Use background workers with retry/backoff and a visible failure queue.
[RECOMMEND] Never let one failed connector stop the dashboard or other connectors.

Security and governance
-----------------------
[RECOMMEND] Audit log for logins, settings, connector changes and incident actions.
[RECOMMEND] Role permissions beyond Admin/Analyst if needed: Viewer and Supervisor.
[RECOMMEND] Rate limits, account lockout and secure password policy.
[RECOMMEND] Backup/restore for database and encrypted settings.
[RECOMMEND] Export an incident report in CSV/PDF without exposing credentials.
[RECOMMEND] Data retention settings and safe archive/purge process.
[RECOMMEND] Production deployment with a proper WSGI server and trusted TLS.

Demonstration quality
---------------------
[RECOMMEND] Dashboard time selector: 1h, 24h, 7d and custom range.
[RECOMMEND] Saved analyst filters and bookmarked investigations.
[RECOMMEND] Empty/loading/error states that clearly explain what is happening.
[RECOMMEND] Demo dataset mode clearly labelled as simulated data.
[RECOMMEND] System status page showing CDSS, database and each SIEM connector.
